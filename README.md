# Jaimez Grocery — Sitio web

Sitio web *one-page* para **Jaimez Grocery**, tienda de abarrotes y productos mexicanos auténticos en **Brick, NJ**. Diseño cálido de mercado mexicano (verde / rojo / blanco), bilingüe español–inglés y optimizado para celular.

🌮 *Productos mexicanos auténticos · Always Quality*

---

## 📍 Información del negocio (NAP)

- **Nombre:** Jaimez Grocery
- **Dirección:** 1017 Cedar Bridge Ave, Brick, NJ 08723
- **Teléfonos:** (609) 832-5274 · (609) 832-5275
- **Horario:** Lunes a Sábado 9:30 AM – 8:00 PM · Domingo 10:00 AM – 7:00 PM

- **Servicios:** Envíos de dinero Maxi Send · NJ Lottery

---

## ✨ Características

- **Una sola página** (one-page), responsive y *mobile-first*.
- **Bilingüe ES / EN** con detección automática del idioma del navegador y botón para cambiar.
- **Indicador "Abierto / Cerrado" dinámico**, calculado con la hora real de Nueva Jersey (`America/New_York`).
- **Botones funcionales:** Llamar (`tel:`), Cómo llegar (Google Maps) y mapa embebido.
- **Datos estructurados Schema.org** (`GroceryStore`) para SEO local.
- Secciones: Hero · Sobre nosotros · Productos · Servicios · Ubicación y horario · Footer.
- Fotos del negocio **retocadas con IA** (Kie AI · Nano Banana) para verse limpias y profesionales.

---

## 🛠️ Tecnología

- HTML + CSS + JavaScript **sin frameworks** (un solo archivo `index.html`).
- Tipografías: Pacifico · Poppins · Inter (Google Fonts).
- Hospedaje: **Cloudflare Pages**.

## ▶️ Verlo localmente

```bash
cd jaimez-grocery-website
python3 -m http.server 8000
# abrir http://localhost:8000
```
